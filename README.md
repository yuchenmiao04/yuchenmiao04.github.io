# Yuchen Miao — Academic Homepage

Source for [Yuchen Miao's academic homepage](https://pnemo04.github.io), built for research communication and PhD applications.

The site presents selected publications, research experience, education, honors, and a downloadable academic CV. It is based on the open-source [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template and is deployed with GitHub Pages.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.
